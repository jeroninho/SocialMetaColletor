## 🎯 Visão Geral

Esta landing page foi projetada para promover uma plataforma SaaS que ajuda equipes a criar, manter e escalar design systems. A página apresenta uma interface moderna com animações interativas, destacando os principais recursos e benefícios da plataforma.

### Principais Características

- 🎨 **Design Moderno**: Interface limpa e profissional com foco em usabilidade
- ✨ **Animações 3D**: Cena interativa no hero section com elementos flutuantes
- 📱 **Totalmente Responsivo**: Otimizado para todos os dispositivos
- 🎭 **Sistema de Design Completo**: 50+ componentes UI reutilizáveis
- 🚀 **Performance Otimizada**: Construído com as melhores práticas do React
- 🎨 **Tailwind CSS v4**: Usando a versão mais recente com CSS variables

## 🎨 Sistema de Design

### Cores (CSS Variables)

#### Light Mode
```css
--background: #ffffff
--foreground: oklch(0.145 0 0)
--primary: #030213
--secondary: oklch(0.95 0.0058 264.53)
--muted: #ececf0
--accent: #e9ebef
--destructive: #d4183d
--border: rgba(0, 0, 0, 0.1)
```

#### Dark Mode
```css
--background: oklch(0.145 0 0)
--foreground: oklch(0.985 0 0)
--primary: oklch(0.985 0 0)
--secondary: oklch(0.269 0 0)
--muted: oklch(0.269 0 0)
--accent: oklch(0.269 0 0)
--destructive: oklch(0.396 0.141 25.723)
```

### Tipografia

```css
--font-size: 14px (base)
--font-weight-normal: 400
--font-weight-medium: 500
```

**Escalas:**
- h1: 2xl (customizável via Tailwind)
- h2: xl
- h3: lg
- h4: base
- p: base
- button: base (medium)
- label: base (medium)

### Espaçamento & Border Radius

```css
--radius: 0.625rem
--radius-sm: calc(var(--radius) - 4px)
--radius-md: calc(var(--radius) - 2px)
--radius-lg: var(--radius)
--radius-xl: calc(var(--radius) + 4px)
```

## 📦 Instalação

### Pré-requisitos
- Node.js 18+ 
- pnpm (recomendado) ou npm

### Passos

1. **Clone o repositório**
```bash
git clone <repository-url>
cd code
```

2. **Instale as dependências**
```bash
pnpm install
```

3. **Execute o servidor de desenvolvimento**
```bash
pnpm dev
```

O servidor estará disponível através do preview surface do Figma Make.

## 🎯 Personalização

### Alterando Cores

Edite o arquivo `src/styles/globals.css` e modifique as CSS variables:

```css
:root {
  --primary: #030213;
  --secondary: oklch(0.95 0.0058 264.53);
  /* ... outras cores ... */
}
```

### Adicionando Novos Componentes

1. Crie um novo arquivo em `src/components/`
2. Importe e use no `App.tsx`
3. Use os componentes UI de `src/components/ui/` para consistência

### Modificando Animações

A animação 3D do Hero está em `src/components/HeroSection.tsx`:
- Ajuste valores de `Math.sin()` e `Math.cos()` para mudar movimento
- Modifique `offset` para alterar timing entre cards
- Personalize as transformações 3D no `transform` CSS

## 🎨 Boas Práticas

1. **Use os componentes UI**: Sempre prefira os componentes da pasta `ui/` para manter consistência
2. **Siga o design system**: Use as CSS variables definidas em `globals.css`
3. **Mantenha responsividade**: Use classes Tailwind responsivas (sm:, md:, lg:)
4. **Acessibilidade**: Os componentes Radix UI já são acessíveis por padrão
5. **Performance**: Use `React.memo()` e `useMemo()` quando necessário

## 📝 Notas Técnicas

### Tailwind CSS v4
Este projeto usa Tailwind CSS v4 com o novo sistema de configuração baseado em CSS:
- Não há `tailwind.config.js`
- Configuração via `@theme inline` no CSS
- Use CSS variables para personalização

### Componentes Radix UI
Todos os componentes interativos usam Radix UI como base:
- Totalmente acessíveis (ARIA)
- Suporte a teclado
- Sem estilos opinionados
- Customizáveis com Tailwind

### Motion (Framer Motion)
Importar usando:
```typescript
import { motion } from "motion/react"
```

### Estrutura de Estilos
```
src/styles/index.css (importa globals.css)
  └── globals.css (variáveis, temas, tipografia base)
```
