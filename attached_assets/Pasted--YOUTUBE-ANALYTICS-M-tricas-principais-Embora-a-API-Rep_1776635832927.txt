# YOUTUBE ANALYTICS

# Métricas principais

Embora a API Reporting do YouTube esteja sujeita à política de descontinuação definida nos [Termos de Serviço](https://developers.google.com/youtube/terms?hl=pt-br), as métricas não principais (e dimensões não principais) não estão sujeitas à política. Nas definições desta página, qualquer métrica que seja uma métrica principal é identificada explicitamente como tal.

A lista abaixo identifica as métricas principais da API. Qualquer uma dessas métricas que também seja usada na API YouTube Analytics também é uma métrica principal nessa API.

### Ver métricas

**engaged_views (métrica principal)**O número de vezes que os vídeos do canal foram assistidos após os segundos iniciais.**visualizaciones (métrica principal)**O número de vezes que um vídeo foi assistido. Em um relatório de playlist, a métrica indica o número de vezes que um vídeo foi assistido no contexto de uma playlist. A [Central de Ajuda do YouTube](http://support.google.com/youtube/bin/static.py?topic=1714326&guide=1714169&page=guide.cs&answer=1714329&hl=pt-br) oferece mais informações sobre como as visualizações são informadas. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**red_views**O número de vezes que um vídeo foi assistido por assinantes do YouTube Premium (antes conhecido como YouTube Red).**views_percentage (métrica principal)**A porcentagem de espectadores que estavam conectados ao assistir o vídeo ou a playlist. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).

### Métricas de alcance

**video_thumbnail_impressions**O número de vezes que as miniaturas de vídeo foram mostradas aos espectadores. Uma impressão é contabilizada quando pelo menos 50% da miniatura estiver visível na tela durante mais de um segundo. Consulte a [Central de Ajuda do YouTube](https://support.google.com/youtube/answer/9314486?hl=pt-br) para mais informações.**video_thumbnail_impressions_ctr**A porcentagem de impressões que resultaram em um clique para assistir o vídeo. Isso é calculado como cliques divididos por impressões.

### Métricas de tempo de exibição

**watch_time_minutes (métrica principal)**O número de minutos que os usuários assistiram vídeos para o canal, o proprietário do conteúdo, o vídeo ou a playlist especificados. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**red_watch_time_minutes**O número de minutos que os assinantes do YouTube Premium (antes conhecido como YouTube Red) assistiram a um vídeo.**average_view_duration_seconds (métrica principal)**A duração média, em segundos, das reproduções de vídeo. A partir de 13 de dezembro de 2021, essa métrica exclui o tráfego de [clipes em loop](https://support.google.com/youtube/answer/10332730?hl=pt-br). Em um relatório de playlist, a métrica indica a duração média, em segundos, das reproduções de vídeo que ocorreram no contexto de uma playlist. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**average_view_duration_percentage**A porcentagem média de um vídeo assistido durante uma reprodução. A partir de 13 de dezembro de 2021, essa métrica exclui o tráfego de [clipes em loop](https://support.google.com/youtube/answer/10332730?hl=pt-br).

### Métricas de engajamento

**comentarios (métrica principal)**O número de vezes que os usuários comentaram um vídeo. Consulte a [Central de Ajuda do YouTube](http://support.google.com/youtube/bin/static.py?topic=1715101&guide=1714169&page=guide.cs&hl=pt-br) para mais informações. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**likes (métrica principal)**A quantidade de vezes que os usuários indicaram que gostaram de um vídeo atribuindo uma classificação positiva. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**dislikes (métrica principal)**O número de vezes que os usuários indicaram que não gostaram de um vídeo atribuindo uma classificação negativa. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**shares (métrica principal)**O número de vezes que os usuários compartilharam um vídeo usando o botão **`Share`**. Consulte a [Central de Ajuda do YouTube](http://support.google.com/youtube/bin/static.py?topic=1733021&guide=1714169&page=guide.cs&hl=pt-br) para mais informações. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).**subscribers_gained (métrica principal)**O número de vezes que os usuários se inscreveram em um canal. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).Os canais podem ganhar ou perder inscritos em vários lugares, incluindo a página de exibição de vídeos, a página do canal e o guia que aparece na página inicial do YouTube. Para identificar o número de novos inscritos no canal que não se inscreveram em uma página de exibição de vídeos, um relatório básico de atividade do usuário contém uma linha que não especifica um valor de dimensão [video_id](https://developers.google.com/youtube/reporting/v1/reports/dimensions?hl=pt-br#video_id). Essa linha também especifica um valor para a métrica **`subscribersLost`**, mas não especifica valores para outras métricas.**subscribers_lost (métrica principal)**O número de vezes que os usuários cancelaram a inscrição em um canal. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).Os dados dessa métrica são informados de maneira semelhante à métrica **`subscribers_gained`**. Para identificar o número de usuários que cancelaram a inscrição, mas não cancelaram a inscrição em uma página de exibição de vídeos, um Relatório de atividade do usuário básico contém uma linha que não especifica um valor de dimensão [video_id](https://developers.google.com/youtube/reporting/v1/reports/dimensions?hl=pt-br#video_id). Essa linha também especifica um valor para a métrica **`subscribers_gained`**, mas não especifica valores para outras métricas.**videos_added_to_playlists**O número de vezes que os vídeos foram adicionados a qualquer playlist do YouTube. Os vídeos podem ter sido adicionados à playlist do proprietário do vídeo ou às playlists de outros canais.O valor da métrica inclui o número de vezes que os vídeos foram adicionados a playlists padrão, como a playlist "Assistir mais tarde". No entanto, ela não conta as playlists em que um vídeo é adicionado automaticamente, como a playlist de uploads de um canal ou o histórico de exibição de um usuário.Essa métrica retorna um número absoluto, o que significa que, se um usuário adicionar um vídeo a uma playlist, remover e adicionar novamente, o valor da métrica vai refletir o vídeo sendo adicionado a uma playlist duas vezes. Os dados dessa métrica não estão disponíveis para datas anteriores a 1º de outubro de 2014.**videos_removed_from_playlists**O número de vezes que os vídeos foram removidos de qualquer playlist do YouTube. Os vídeos podem ter sido removidos da playlist do proprietário do vídeo ou das playlists de outros canais.O valor da métrica inclui o número de vezes que os vídeos foram removidos de playlists padrão, como a playlist "Assistir mais tarde".Essa métrica retorna um número absoluto, o que significa que, se um usuário adicionar um vídeo a uma playlist, remover, adicionar novamente e remover novamente, o valor da métrica vai refletir o vídeo sendo removido de uma playlist duas vezes. Os dados dessa métrica não estão disponíveis para datas anteriores a 1º de outubro de 2014.

### Métricas de playlists

Os relatórios de playlists contêm dois tipos de métricas que explicam como os espectadores interagem com os vídeos em uma playlist:

- **Métricas de vídeo agregadas** fornecem métricas de atividade do usuário e de impressão que são agregadas para todos os vídeos na playlist que também são de propriedade do canal que possui a playlist. As métricas de vídeos de outros canais não são calculadas na agregação. Como resultado, se um canal criar uma playlist que contenha apenas vídeos de outros canais, os relatórios dessas playlists não vão fornecer valores para essas métricas.
    
    Consulte as seções de [métricas de visualização](https://developers.google.com/youtube/reporting/v1/reports/metrics?hl=pt-br#View_Metrics) e [métricas de tempo de exibição](https://developers.google.com/youtube/reporting/v1/reports/metrics?hl=pt-br#Watch_Time_Metrics) deste documento para definições de métricas de vídeo agregadas compatíveis.
    
- **Métricas na playlist** refletem a atividade do usuário e o engajamento no contexto da página da playlist. Essas métricas incluem visualizações de todos os vídeos na playlist, independentemente de qual canal os possui, mas contam apenas as visualizações que ocorreram no contexto da playlist.

A maioria das métricas a seguir são métricas na playlist. As métricas restantes na lista, como a métrica **`playlistSaves`**, são sobre interações do usuário com a playlist em si e não com vídeos na playlist. Como tal, essas métricas não seriam caracterizadas como métricas de vídeo agregadas ou métricas na playlist.

**playlist_starts**O número de vezes que os espectadores iniciaram a reprodução de uma playlist. Essa métrica inclui apenas visualizações de playlists que ocorreram na Web.**playlist_saves_added (com suporte apenas na API Reporting do YouTube)**O número de vezes que os usuários salvaram uma playlist. Consulte a [Central de Ajuda do YouTube](https://support.google.com/youtube/answer/4541577?hl=pt-br) para mais informações sobre playlists salvas. Essa métrica retorna um número absoluto, o que significa que, se um usuário salvar uma playlist, remover da lista de playlists salvas e salvar novamente, o valor da métrica vai refletir duas playlists salvas sendo adicionadas.**playlist_saves_removed (com suporte apenas na API Reporting do YouTube)**O número de vezes que os usuários removeram a playlist das listas de playlists salvas. Essa métrica retorna um número absoluto, o que significa que, se um usuário salvar uma playlist, remover da lista de playlists salvas, salvar novamente e remover novamente, o valor da métrica vai refletir duas playlists salvas sendo removidas.

### Métricas de anotações

**annotation_impressions**O número total de impressões de anotações.**annotation_clickable_impressions**O número de anotações que apareceram e puderam ser clicadas.**annotation_clicks**O número de anotações clicadas.**annotation_click_through_rate (métrica principal)**A proporção de anotações que os espectadores clicaram no número total de impressões de anotações clicáveis. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br). A Central de Ajuda do YouTube tem mais informações sobre [como criar anotações](http://support.google.com/youtube/bin/answer.py?answer=92710&topic=2802217&ctx=topic&hl=pt-br) e [usar anotações de link](http://support.google.com/youtube/bin/answer.py?answer=1092582&topic=2802217&ctx=topic&hl=pt-br).**annotation_closable_impressions**O número de anotações que apareceram e puderam ser fechadas.**annotation_closes**O número de anotações fechadas.**annotation_close_rate (métrica principal)**A proporção de anotações que os espectadores fecharam no número total de impressões de anotações. This is a core metric and is subject to the [Deprecation Policy](https://developers.google.com/youtube/youtube-api-list?hl=pt-br).

### Métricas de cards

A Central de Ajuda do YouTube contém instruções mais detalhadas para [adicionar cards aos seus vídeos](https://support.google.com/youtube/answer/6140493?ref_topic=6140492&hl=pt-br) e o [relatório de cards do YouTube Analytics](https://support.google.com/youtube/answer/6165415?hl=pt-br).

**card_impressions**O número de vezes que os cards foram exibidos. Quando o painel do card é aberto, uma impressão é registrada para cada card do vídeo.**card_clicks**O número de vezes que os cards foram clicados.**card_click_rate**A taxa de cliques para cards, que é calculada como a proporção de cliques em cards para impressões de cards.**card_teaser_impressions**O número de vezes que os teasers de card foram exibidos. Uma visualização de vídeo pode gerar várias impressões de teaser.**card_teaser_clicks**O número de cliques em teasers de card. Os cliques no ícone de card interativo são atribuídos ao último teaser exibido ao usuário.**card_teaser_click_rate**A taxa de cliques para teasers de card, que é calculada como a proporção de cliques em teasers de card para o número total de impressões de teasers de card.

### Métricas da tela final

As telas finais são elementos que aparecem durante os últimos cinco a 20 segundos de um vídeo para promover seu conteúdo, canal e sites. A Central de Ajuda do YouTube contém instruções mais detalhadas para [adicionar telas finais aos seus vídeos](https://support.google.com/youtube/answer/6388789?hl=pt-br) e o [relatório de telas finais do YouTube Analytics](https://support.google.com/youtube/answer/7000682?hl=pt-br).

**end_screen_element_impressions**O número de elementos da tela final que foram exibidos. Uma impressão é registrada para cada elemento da tela final que é exibido.**end_screen_element_clicks**O número de vezes que os elementos da tela final foram clicados.**end_screen_element_click_rate**A taxa de cliques para elementos da tela final, que é calculada como a proporção de cliques em elementos da tela final para impressões de elementos da tela final.

### Métricas de cancelamento de assinatura

**membershipsCancellationSurveyResponses**O número de pesquisas concluídas por usuários do YouTube que cancelaram a assinatura do canal especificado durante o período do relatório.

### Métricas de receita estimada

**Observação**:as métricas de receita estimada estão sujeitas a ajustes no final do mês e não incluem publicidade vendida e veiculada por parceiros. Consulte a [Central de Ajuda do YouTube](https://support.google.com/youtube/answer/1714384?hl=pt-br) para mais informações e observações sobre os valores de receita estimada.

A API YouTube Reporting informa todos os valores de receita estimada e ganhos em dólares americanos.

**estimated_partner_revenue (métrica principal)**A receita líquida total estimada de todas as origens de publicidade vendidas pelo Google, bem como de origens não publicitárias para o período e a região selecionados.**estimated_partner_ad_revenue**A receita líquida total estimada de todas as origens de publicidade vendidas pelo Google para o período e a região selecionados.As métricas de receita estimada estão sujeitas a ajustes no final do mês e não incluem publicidade vendida e veiculada por parceiros.**estimated_partner_ad_auction_revenue (com suporte apenas na API do YouTube Reporting)**O total de ganhos estimados (receita líquida) de publicidade vendida por leilão pelo Google AdSense para o período e a região selecionados. Essa métrica era chamada anteriormente de **`estimated_partner_ad_sense_revenue`**.**estimated_partner_ad_reserved_revenue (com suporte apenas na API de relatórios do YouTube)**O total de ganhos estimados (receita líquida) de publicidade vendida por reserva pelo DoubleClick (DCLK) e outras origens vendidas pelo YouTube. Essa métrica era chamada anteriormente de **`estimated_partner_double_click_revenue`**.**estimated_partner_red_revenue (com suporte apenas na API Reporting do YouTube)**O total de ganhos estimados (receita líquida) de assinaturas do YouTube Premium (antes conhecido como YouTube Red).**estimated_partner_transaction_revenue (com suporte apenas na API Reporting do YouTube)**A receita total estimada de transações, como conteúdo pago e financiamento de fãs, menos os reembolsos cobrados pelo parceiro.

### Métricas de performance do anúncio

**estimated_youtube_ad_revenue**A receita bruta estimada, em dólares americanos, de toda a publicidade vendida pelo Google ou pelo parceiro do DoubleClick para o período e a região selecionados. A receita bruta está sujeita a ajustes mensais e não inclui anúncios veiculados por parceiros. A receita bruta não deve ser confundida com a receita estimada ou a receita líquida, que considera sua participação na propriedade e nos contratos de participação na receita.**estimated_cpm**A receita bruta estimada por mil impressões de anúncios.**ad_impressions**O número de impressões de anúncios verificadas veiculadas.**estimated_monetized_playbacks**O número de instâncias em que um espectador assistiu seu vídeo e recebeu pelo menos uma impressão de anúncio. A reprodução monetizada é contabilizada se um anúncio precedente for exibido ao espectador e este cancelar a exibição do anúncio antes de seu vídeo começar. O erro estimado esperado para este valor é de cerca de 2%.**estimated_playback_based_cpm**A receita bruta estimada por mil reproduções.
